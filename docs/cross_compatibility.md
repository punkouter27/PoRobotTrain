# Cross-compatibility: the pinned contract, the guard, the registry

PoRobotTrain is one of several Po apps whose policies are meant to be interchangeable. This file records
the three pieces that make that checkable here. The rules themselves live in `global/UNITE/RULES.md`;
this is the local implementation and its current state.

## 1. `contracts.lock.json` — the pin

A copy of the numbers that must not drift: `n_obs`, `n_action`, `control_dt`, `decimation`, `timestep`,
the MuJoCo version, the three contract hashes, and the list of **legacy interfaces** that already exist
in the wild.

It carries enough for CI to check shapes without `global/UNITE` on disk, which matters because
`global/` is not a repo and never appears in a fresh clone.

```powershell
.venv/Scripts/python.exe scripts/pin_contract.py --check   # exit 1 when the pin is stale
.venv/Scripts/python.exe scripts/pin_contract.py           # re-pin (a deliberate act)
```

Re-pinning is a breaking change: a changed `interface_sha256` invalidates every policy trained against
the old one.

## 2. `RobotControl/configs/contract.py` — the one source

Everything that needs an interface number reads it from here instead of hard-coding it.

```python
from robotcontrol.configs import contract as C

c = C.load()                    # 131 / 28, 50 Hz, 4-step decimation
c.assert_io(env.num_obs, env.num_actions)   # raises ContractMismatch on a wrong width
c.describe_io(23, 7)            # "legacy"
c.role_of("left_hip_pitch_joint")           # "hip_pitch_l"  (needs global/UNITE present)
```

Two modes: **lock-only** (always available, used by CI) and **full** (adds roles, joint table, motor
slots when `global/UNITE/creatures/unitree_r1_a5/contract.json` is present, and refuses to load if its
hashes disagree with the lock).

## 3. `RobotControl/training/policy_guard.py` — the gate

Called at the end of every export (`export_level0.py`, `train_head_skill.py`). It shells out to
`global/UNITE/tools/verify_policy.py` and classifies the result:

| Result | Meaning | Behaviour |
|---|---|---|
| **conforming** | 131 / 28, hashes line up | pass, optionally write the sidecar |
| **legacy** | matches a recorded legacy interface | **export allowed**, logged as non-portable |
| **foreign** | neither | **abort** — a new interface nobody signed off on |

`UNITE_STRICT=1` turns legacy into an abort. Flip it the day the trainer moves to the role-ordered
interface, not before — the twin cannot yet feed 131 observations, so strict mode would stop every
export in the repo.

If `global/UNITE` is absent (CI, fresh clone) the guard prints **NOT VERIFIED** and continues; the lock
still pins the shapes, so nothing is silently unguarded.

## 4. `agents/registry.json` — what exists today

Generated by `scripts/agent_registry.py`, keyed by `policy_sha256` so duplicate copies collapse.

```
.venv/Scripts/python.exe scripts/agent_registry.py --check
```

Current state (2026-11-26): **12 files on disk, 6 distinct policies, 0 conforming, 6 legacy.**

| policy | shape | legacy interface |
|---|---|---|
| `r1_level0_upperbody` | 23 / 7 | `r1_level0_upperbody` |
| `look_at`, `glance_around`, `hold_centre` | 9 / 2 | `r1_head_skill` |
| `nod_yes`, `shake_no` | 6 / 1 | `r1_head_skill_single` |
| walk sandbox (not in this repo) | 83 / 24 | `r1_level2_velocity` |

Every one of these carries normalisation **inside** the ONNX graph, which the guard reports as an R9
violation. That is why they are grandfathered and can never be ported — only retrained.

## What is still missing

- **Nothing trains on the 131 / 28 interface yet.** The trainer, the observation builder and the UE twin
  all still speak the legacy shapes.
- **The twin cannot feed 131 observations.** That has to land before the first role-ordered policy is
  trained, otherwise the result cannot be played.
- **`UNITE_STRICT` is off.** Correct for now; wrong after the first conforming policy ships.

Order of work is in the RULES.md §5 sequence and was agreed here: Parts 1 and 5 (this file), then the
guard in the export path (done), then the twin, then one end-to-end head skill.

One shared piece that unlocks half the list

A "ghost command bus" in the browser twin. One small JS module in wwwroot/js/twin/ takes a target pose from any source: gamepad, webcam, gaze, voice, beat, game, timeline or LLM. It clamps the pose to 0.9 of the joint range from twin_manifest.json, runs the Rapier contact check in collide.js, and draws it as the ghost. It never writes to the robot.

Ideas #1, #6, #8, #9, #11, #12, #13 and #14 become thin adapters on top of it. Build it once with #1 and each later input costs about half as much.
